There are methods to test piles and see if they work. We will load it all the way to failure. A pile load test NEEDS to happen. The number of pile load tests will depend on how many piles there are for the project. 

The testing pile will be tested up to 200% the design load. This is a destructive test, so the testing pile may be destroyed and become unusable. So we just leave it there after testing. 

Bringing deadweights to put on top of the pile is difficult. We usually just stack whatever we already have at the site (such as concrete slabs), girders, steel, whatever. 

We can also use a jack to try to push down on the test pile, while it's connected to "reaction piles". The reaction piles will be in tensions, while the test pile will be in compression.
