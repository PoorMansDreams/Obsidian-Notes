- Background Research
	- Stakeholders
	- Existing tools and solutions
- Specify Requirements
	- Characteristics the design must meet in order to be successful
	- Cost, time to completion, environmental impact, useful life, codes and safety, equity, sustainability, etc.
	- Overconstrained - too many requirements
	- Underconstrained - not enough requirements. 
- Brainstorm Evaluate and Choose solution
	- Robustness, elegance, aesthetics, cost, resources, time, skill required, safety. 
- Develop and Prototype Solution
	- Use technical skills to write up reports and get results
- Test Solution
	- See if the results fulfill requirements and qualifies
- Communicate Results
	- Solution must be communicated
	- clear and concise communications
	- manage expectations, using diagrams, tables, figures, text, etc.
